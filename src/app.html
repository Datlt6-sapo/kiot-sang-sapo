Kiot sang Sapo

Thả file “Danh sách hàng hóa” hoặc “Danh sách khách hàng” xuất từ KiotViet. Ứng dụng tự nhận loại file, điền vào đúng file mẫu nhập của Sapo và tải về máy. Dữ liệu chỉ xử lý trên máy bạn, không gửi đi đâu.

Kéo thả file KiotViet vào đây .xlsx hoặc .xls · chọn được nhiều file một lúc Chọn file
Trình duyệt có thể hỏi “Cho phép tải nhiều file” lần đầu, hãy chọn Cho phép.
File Sapo được tạo

Sản phẩm đơn lẻ Quy đổi = 1

Mẫu “Mẫu file nhập”. Giá lấy Giá bán sau thuế nếu có, tồn kho vào cột Cửa hàng chính_Tồn kho.

Sản phẩm quy đổi Quy đổi ≠ 1

Thùng, lốc, combo… nối về SKU gốc qua Mã ĐVT Cơ bản hoặc Mã HH Liên quan. Alias sinh từ tên sản phẩm gốc.

Khách hàng DMHC 63 tỉnh

Tỉnh, Quận/Huyện, Phường/Xã chỉ điền khi khớp chính xác danh mục Sapo. Khách không có SĐT được gán 0900000001, 0900000002…

Công nợ Nợ ≠ 0

Lấy Nợ cần thu hiện tại, giữ dấu âm/dương, bỏ khách có nợ bằng 0. Khớp khách theo cùng SĐT với file khách hàng.

Thứ tự nhập vào Sapo
  1. Sản phẩm đơn lẻ, rồi mới tới Sản phẩm quy đổi (quy đổi cần sản phẩm gốc có sẵn).
  2. Khách hàng, rồi mới tới Công nợ (công nợ tìm khách theo SĐT).
Mỗi file sản phẩm là một chi nhánh. Có nhiều chi nhánh thì xuất và chuyển từng file.
